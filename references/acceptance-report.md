## 6. Ограничения MVP

- Нет настоящей потоковой обработки: файл читается в память.
- Нет отмены длительных заданий.
- Смена пароля есть в слое хранения, но не выведена в UI.
- Минимум 8 символов пароля, без оценки энтропии.
- Нет блокировки после неудачных попыток.
- Нет предпросмотра первых 20 строк.
- Только русский интерфейс.
- Нет PyInstaller-сборки.
- Нет метаданных XLSX.
- Уничтожение проекта не гарантирует forensic-стирание.
- Исходные и восстановленные файлы в `uploads/` хранятся в открытом виде.
- `project.json` хранит `sample` — первый пример значения столбца.

## 7. Вердикт

Реализация выполняет ключевые инварианты ТЗ и полный сценарий
«анонимизация → экспорт → восстановление». Ограничения MVP описаны честно и не
скрывают расхождений с ТЗ.
