# Исходные материалы

В этом каталоге лежат документы, по которым собран проект.

| Файл | Назначение | Статус |
|---|---|---|
| [`requirements.md`](requirements.md) | исходное техническое задание LTA: инварианты I1–I6, функциональные и нефункциональные требования, архитектура, критерии приёмки | только чтение |
| [`acceptance-report.md`](acceptance-report.md) | отчёт о проверке реализации: тесты, E2E, браузер, ограничения | обновляется по итогам проверок |

## Правила

- `requirements.md` — это исходное ТЗ. Не переписывайте его под реализацию.
- Если требование ТЗ не реализовано, это фиксируется в отчёте и README, а не
  удаляется из ТЗ.
- Все имена, телефоны, адреса, паспорта и суммы в демонстрационных данных
  синтетические. Реальные персональные данные в репозиторий не добавляются.
- Демонстрационная таблица генерируется скриптом
  [`scripts/make_demo.py`](../scripts/make_demo.py) и не коммитится.

## Приоритет источников

1. Инварианты I1–I6 из ТЗ — блокирующие.
2. Функциональные требования F1–F9.
3. Нефункциональные требования N1–N6.
4. Критерии приёмки из раздела 9 ТЗ.

Если реализация расходится с ТЗ, решение фиксируется явно: в README, в разделе
«Ограничения», и в `acceptance-report.md`.
