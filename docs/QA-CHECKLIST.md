# QA-чек-лист Local Table Anonymizer

## 1. Автоматические проверки

Выполняются из корня репозитория.

```bash
pip install -r requirements-dev.txt
python3 scripts/validate.py
python3 tests/test_lta.py
bash scripts/e2e.sh
```

### Ожидаемые результаты

| Команда | Ожидание |
|---|---|
| `python3 scripts/validate.py` | `OK: структура, инварианты, офлайн-ограничения и отсутствие секретов проверены` |
| `python3 tests/test_lta.py` | `6/6 тестов прошли` |
| `bash scripts/e2e.sh` | `OK: полный сценарий анонимизации и восстановления через веб-API работает` |

### Что покрывают юнит-тесты

- [x] `test_roundtrip` — `INDEX`-значения восстанавливаются байт-в-байт.
- [x] `test_determinism` — одинаковые значения дают одинаковые псевдонимы;
  разные проекты дают разные псевдонимы.
- [x] `test_wrong_password` — неверный пароль отклоняется.
- [x] `test_hash_mask` — `HASH` детерминирован и сохраняет длину; `MASK`
  скрывает части значения.
- [x] `test_offline` — сетевые вызовы заблокированы.
- [x] `test_tableio_roundtrip` — CSV читается и пишется без потерь.

### Что покрывает E2E

- [x] Страница отдаётся и содержит API-токен.
- [x] Запрос с неверным токеном получает `403`.
- [x] Создание проекта.
- [x] Загрузка `demo.csv` на 5000 строк и 11 столбцов.
- [x] Автоопределение: ФИО, телефон, email, дата рождения, город, адрес,
  паспорт получают `INDEX`.
- [x] Анонимизация 5000 строк.
- [x] Скачивание анонимной таблицы.
- [x] Загрузка анонимной таблицы и деанонимизация.
- [x] `not_found == 0`.
- [x] Совпадение всех `INDEX`-столбцов с оригиналом.
- [x] Удаление тестового проекта и словаря.

## 3. Проверка безопасности

- [x] В коде приложения нет `requests`, `urllib`, `httpx`, `aiohttp`, `socket`.
- [x] В интерфейсе нет внешних URL, шрифтов, CDN и картинок.
- [x] Сервер слушает только `127.0.0.1`.
- [x] API требует токен; неверный токен → `403`.
- [x] `opencode.json`, `opencodemcp.json`, `.env` отсутствуют в репозитории.
- [x] `.gitignore` исключает `demo.csv`, `uitest_*`, `__pycache__`,
  `.DS_Store`, архивы и PDF.
- [x] `scripts/validate.py` не находит секретов.
- [x] В словаре хранится только `orig_enc` (AES-GCM), а не открытый текст.
- [x] `project.json` не содержит исходных значений, кроме `sample` (осознанное
  ограничение MVP).
- [x] `destroy` перезаписывает `mapping.db` и удаляет каталог проекта.
