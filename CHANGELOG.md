## [1.0.0] — 2026-11-08

Первый публичный релиз учебного MVP Local Table Anonymizer.

### Добавлено

- локальный Flask-интерфейс на `127.0.0.1` со случайным API-токеном;
- создание, открытие, закрытие и уничтожение проекта;
- импорт CSV (UTF-8 с BOM, UTF-8, CP1251; разделители `,`, `;`, табуляция) и
  XLSX/XLSM;
- автоопределение типа столбца по заголовку и значениям;
- режимы `INDEX`, `HASH`, `MASK`, `KEEP`;
- детерминированные псевдонимы `PREFIX_` + HMAC-SHA256;
- нормализация телефонов, email и пробелов перед хэшированием;
- обработка дубликатов и коллизий;
- зашифрованный словарь `mapping.db` на AES-256-GCM;
- вывод ключей через scrypt + HKDF-SHA256;
- проверка пароля через KDF-верификатор;
- прогресс анонимизации и деанонимизации;
- отчёт по столбцам и восстановленным значениям;
- экспорт анонимной и восстановленной таблиц в CSV/XLSX;
- уничтожение проекта с перезаписью словаря;
- адаптивная тёмная тема для 1440, 768, 390 и 360 px;
- встроенная data-URI иконка без внешних запросов.

### Проверки

- 6 юнит-тестов: round-trip, детерминированность, неверный пароль, HASH/MASK,
  офлайн, CSV round-trip;
- сквозной HTTP-тест: 5000 строк, 7 `INDEX`-столбцов, 34 689 восстановленных
  значений, 0 расхождений;
- `scripts/validate.py`: структура, инварианты, отсутствие секретов и сетевых
  вызовов;
- GitHub Actions на Python 3.11, 3.12 и 3.13;
- браузерная проверка на 1440, 768, 390 и 360 px.

### Безопасность

- приложение не выполняет сетевых запросов;
- слушает только loopback;
- словарь шифруется на уровне значений;
- пароль не хранится;
- секретные конфиги и сгенерированные таблицы исключены из репозитория.

### Ограничения

- файл читается в память целиком, настоящей потоковой обработки нет;
- нет отмены заданий;
- смена пароля не выведена в UI;
- минимум 8 символов пароля, без оценки энтропии;
- нет блокировки после неудачных попыток;
- нет предпросмотра первых 20 строк;
- только русский интерфейс;
- нет PyInstaller-сборки;
- уничтожение проекта не гарантирует forensic-стирание;
- исходные и восстановленные файлы в `uploads/` хранятся в открытом виде.
